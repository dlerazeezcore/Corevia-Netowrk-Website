# Corevia Network AI Studio Package

## What this package is for
This package prepares all inputs AI Studio needs to generate the final Corevia Network website in the same visual direction as the downloaded template reference.

## What AI Studio should do
- Read and use `AI_STUDIO_PROMPT.md` as the master generation prompt.
- Use files in `template-reference/` to match visual style and layout language.
- Use brand assets in `assets/`.

## Which file to paste into AI Studio
- `AI_STUDIO_PROMPT.md`

## Asset locations
- Corevia logo:
  - `assets/corevia/corevia-network-logo.svg` (primary)
  - `assets/corevia/corevia-network-logo.png` (fallback)
- Tulip Booking logo:
  - `assets/tulip-booking/tulip-booking-logo.svg`
  - `assets/tulip-booking/tulip-booking-logo.png`
- App links:
  - `assets/app-links/app-store-link.txt`
  - `assets/app-links/google-play-link.txt`

## Template style reference files
- `template-reference/images/preview.jpg`
- `template-reference/stylesheets/style.css`
- `template-reference/stylesheets/sub-style.css`
- `template-reference/stylesheets/_sub-base-variable.scss`
- `template-reference/template.conf`
- `template-reference/sub-visual-editor.conf`

## Style analysis
- `style-analysis/TEMPLATE_STYLE_ANALYSIS.md`

## Which logo to use
Use `assets/corevia/corevia-network-logo.svg` as primary logo. If SVG rendering fails in AI Studio, use `assets/corevia/corevia-network-logo.png`.

## Tulip Booking links storage
Tulip Booking app links are stored in:
- `assets/app-links/app-store-link.txt`
- `assets/app-links/google-play-link.txt`

## Assumptions made
- Final site is intentionally one-page with anchor navigation only: Home, Services, About Us, Contact Us.
- Contact details beyond the provided text were not invented.
- App store badges may be generated by AI Studio if official badge files are not supplied.

## Scope confirmation
Codex prepared and organized the AI Studio package only. Codex did not build the final website.
